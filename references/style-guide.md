# Style Guide

## Python code
- Follow PEP 8 with 88-character line length
- Use double quotes for strings
- Type hints required for all public functions
- Import order: standard lib, third-party, local

## YAML profiles
- Use 2-space indentation
- Include all required schema fields
- Palette names are case-insensitive (Okabe-Ito, okabe_ito)

## Commit messages
- Prefix with type: feat, fix, docs, test, refactor, chore, ci, build
- Keep under 72 characters for the first line
