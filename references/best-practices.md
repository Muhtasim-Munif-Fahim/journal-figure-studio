# Best Practices

## Data preparation
- Use clean, tidy data (one row per observation)
- Handle missing values before rendering
- Use consistent column naming

## Figure design
- Choose appropriate figure type for your data
- Use colourblind-safe palettes (Okabe-Ito is default)
- Keep fonts legible at print size
- Include error bars / confidence intervals when reporting estimates

## Reproducibility
- Always keep the output package intact
- Share figure_request.yaml and the output package with publications
- Use version control for your figure requests
