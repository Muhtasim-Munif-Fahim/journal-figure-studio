# Glossary

| Term | Definition |
|------|------------|
| Profile | YAML configuration for a specific journal or discipline |
| Figure request | YAML file describing what to render |
| Output package | Self-contained directory with figure files and metadata |
| PALETTE | Named colour scheme from the style section |
| SHA-256 | Hash used for reproducibility verification |
| Stale profile | Profile that hasn't been re-verified within its expiry period |
