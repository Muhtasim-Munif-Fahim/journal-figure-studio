# Project Maturity

## Current status
- **Version**: 0.2.0 (pre-release)
- **API stability**: Breaking changes possible before v1.0
- **Profile format**: May change in minor versions

## Stability guarantees

- Deprecation warnings will be given one minor version before removal
- Profile schema additions are non-breaking; removals are breaking
