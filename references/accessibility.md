# Accessibility Reference

## Colourblind-safe defaults
- Default palette: Okabe-Ito (colourblind-safe for 8 types)
- Maximum contrast between adjacent groups
- Shapes and markers differentiate groups (not just colour)

## Font legibility
- Minimum 7pt font size enforced by validation
- Sans-serif default for readability at small sizes
- Vector output preserves font rendering at any scale
