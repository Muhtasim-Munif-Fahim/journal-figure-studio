# Release v0.2.0

## Changes

- [Feature] Multi-panel subplot support via `figures` list
- [Feature] SVG output via `export_svg` flag or `svg` in profile formats
- [Feature] Statistical significance annotations (p_value → ***/**/*/n.s.)
- [Feature] Custom mplstyle support via profile `style.mplstyle` key
- [Feature] Excel input support (.xls/.xlsx)
- [Feature] `--version` flag on all CLI scripts
- [Feature] `--verbose` flag for debug logging
- [Infrastructure] pyproject.toml, GitHub Actions CI, pre-commit, tox
- [Testing] 80+ tests covering all figure types, edge cases, CLI integration
- [Docs] README badges, supported features table, quick start
