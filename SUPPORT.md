# Support

If you need help with journal-figure-studio:

1. Check the documentation in the `references/` directory
2. Search open/closed issues on GitHub
3. Open a new issue if your problem is not addressed

## Common issues
- Run `python scripts/validate_request.py` on your request file
- Run `python scripts/validate_profile.py` on your profile
- Check the troubleshooting guide in `references/troubleshooting.md`
